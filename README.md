# Easy Ventures Website

A frontend-only React landing page for Easy Ventures. The website does not
require an API server, database, or backend environment variables.

## Run locally

```bash
cd frontend
yarn install
yarn start
```

The development server runs at <http://localhost:3000>.

## Production build

```bash
cd frontend
yarn build
```

Deploy the generated `frontend/build` directory to any static hosting service.
